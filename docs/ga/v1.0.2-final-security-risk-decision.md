# PatrolSafe v1.0.2 Windows payload security decision (internal)

Status: **TEMPORARY RESIDUAL RISK ACCEPTED FOR THE FROZEN, PUBLISHED v1.0.2 BINARY**. Decision recorded and retained 21 September 2026. This is a Vesoft Services Limited business/security decision, not external security certification and not a claim that the remaining advisories do not exist.

- Production inventory SHA-256: `9E7E11AC6DFAE7CD06A915F155A543930BF8B6A6ECA9F6F78E399C50EE1FD24D`

- Desktop-payload critical findings: zero

## Accepted Windows-payload HIGH records

The detailed reachability analysis is preserved in [GA-UAT-08 security disposition](uat08-security-risk-disposition.md). Management accepted temporary residual risk for the reviewed records in these package chains:

- `extract-zip@2.0.1`, `@puppeteer/browsers@2.13.0`, `puppeteer@24.38.0`, `puppeteer-core@24.38.0`, and `whatsapp-web.js@1.34.7`: the archive-extraction vulnerability ships indirectly, but the reviewed installed-Edge/LocalAuth product flow has no customer, WhatsApp or evidence input path to browser archive acquisition/extraction.
- `ip-address@10.1.0`: no reviewed product path passes customer-controlled input to the vulnerable parser.
- `glob@10.4.5`: the vulnerable CLI behavior is not invoked; product glob patterns are fixed.
- `brace-expansion@2.0.2/2.1.0`: no reviewed customer-controlled crafted glob input reaches the vulnerable operation.
- `js-yaml@4.1.1`: no customer YAML import/parse flow was identified.
- `lodash@4.17.21`: no customer-controlled template-imports path was identified.

Compensating controls and follow-up requirements remain as documented in GA-UAT-08. Discovery of a realistically attacker-influenced path, or a change to the packaged dependency/product flow, requires reassessment.

## Non-desktop follow-up

Repository-wide findings in `tar@6.2.1`, `@mapbox/node-pre-gyp@1.0.11`, `bcrypt@5.1.1`, and `nodemailer@6.10.1` were verified absent from the Windows desktop payload. They remain separate build/licence-service remediation work; this decision does not waive them.

## Decision

- [x] **ACCEPT TEMPORARY RESIDUAL RISK FOR v1.0.2** for the reviewed Windows-payload HIGH records above.
- [ ] Block v1.0.2 release on those reviewed records.

Decision authority: Vesoft Services Limited director/operator. The acceptance applies only to the exact frozen binary identified above. It remains recorded after publication.
