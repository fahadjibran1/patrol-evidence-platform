# PatrolSafe by S4 v1.0.1 — release notes

Status: **PUBLIC-TRIAL CANDIDATE — DOWNLOAD NOT AUTHORIZED**

PatrolSafe v1.0.1 is a maintenance release candidate for the 30-day trial. It ensures that active monitoring stops when the local trial expires, without requiring an application restart.

## Trial expiry behavior

- Monitoring stops automatically when the 30-day trial ends.
- Existing evidence remains available.
- Backup remains available.
- Sites, mappings and customer data are preserved.
- PatrolSafe does not log out or unlink the saved WhatsApp session merely because the trial ended.
- A valid Annual licence restores eligibility; the customer then manually resumes monitoring.

## Compatibility

The product remains PatrolSafe by S4 for certified Windows 11 x64 workstations. Workspace timezone, evidence, WhatsApp, backup/restore and Annual licence compatibility remain unchanged. The v1.0.0 controlled-pilot installer remains immutable and is not replaced by this candidate.

PatrolSafe v1.0.1 is currently provided in English. Public download requires separate Vesoft authorization after final signing and release verification.
