> PatrolSafe is available internationally in supported countries and regions, subject to applicable law, sanctions/export restrictions, WhatsApp availability, Microsoft Windows availability and Vesoft commercial availability.

Do not say “available everywhere”, “works in every country”, “globally compliant” or “worldwide legal compliance”. Counsel must approve the country/region scope, sanctions/export treatment, transfers and local-law supplements.

## Certified platform wording

> PatrolSafe v1.0 is certified for Windows 11 x64. It requires a supported Microsoft Edge installation, reliable outbound internet access to WhatsApp Web, an eligible authorised WhatsApp account, and a Windows account permitted to install desktop software and write to selected evidence and backup locations. Customers are responsible for sufficient protected storage. Other Windows versions/architectures, Windows Server, macOS and Linux are not certified by this release record.
