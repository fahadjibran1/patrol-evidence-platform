## Built for patrol operations

PatrolSafe is designed for security-company office administrators and operations managers who need a clear record of patrol evidence without manually sorting images into site folders.

- connect an authorised WhatsApp account;
- discover groups by display name;
- map each approved group to a site;
- start or pause monitoring;
- receive new JPEG and PNG patrol evidence;
- review images, times, sites and integrity information;
- back up and restore the local workspace.

PatrolSafe is not an emergency communications service, alarm receiving centre or substitute for human supervision and incident-response procedures.

## How it works

1. Install the Vesoft-signed Windows application.
2. Create the local company workspace and administrator.
3. Review the workspace time zone and choose protected evidence storage.
4. Link an authorised WhatsApp account using the QR shown by PatrolSafe.
5. Create sites and map approved WhatsApp groups by display name.
6. Start Monitoring. Newly received supported patrol images are organised under the mapped site.
7. Review evidence and create verified backups.

The v1.0 interface and documentation are currently provided in English.

## Windows requirements

PatrolSafe v1.0 is certified for Windows 11 x64. It requires:

- Microsoft Edge, kept supported and updated;
- reliable outbound internet access to WhatsApp Web;
- an eligible, authorised WhatsApp account with linked-device capability;
- a Windows account permitted to install desktop software and write to the chosen evidence and backup locations;
- enough protected local storage for the customer's evidence and retention policy;
- a practical desktop display; release review covered 1366×768 and 1920×1080.

The clean final UAT used Windows 11 Pro 25H2 x64, 2 vCPU and 8 GB RAM. Windows 10, Windows Server, Arm64, macOS and Linux are not certified by this release record. Organisational policy may require administrator approval for installation or removal.

PatrolSafe stores the operational database and evidence on the customer's workstation or customer-selected storage. The audited v1.0 application does not automatically upload the operational database or evidence to Vesoft, and no Vesoft telemetry or cloud-backup client was found.
